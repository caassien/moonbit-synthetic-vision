# Changelog

## 0.1.0

- Created a MoonBit package for deterministic synthetic vision fixtures.
- Added gray/RGB image buffers and Netpbm text exporters.
- Added calibration boards, checkerboards, dot grids, gradients and target
  scenes.
- Added noise, blur and occlusion transforms.
- Added bounding boxes, keypoints, masks, optical-flow samples and manifests.
- Added CLI preview, smoke example, tests and GitHub Actions CI.
