# Roadmap

## 0.1

- Deterministic gray/RGB image primitives.
- Calibration and target scene recipes.
- Detection boxes, masks and optical-flow samples.
- CLI preview, examples, tests and CI.

## 0.2

- Lens distortion and perspective warp helpers.
- COCO-like JSON export for instance annotations.
- More calibration targets: ChArUco-style grids and asymmetric circle grids.
- Dataset split helpers for train/validation/test fixture sets.

## Later

- Optional binary Netpbm export.
- JavaScript target demo page.
- Interop notes for converting PGM/PPM to PNG in external tools.
- Additional benchmark presets for segmentation and optical flow.
